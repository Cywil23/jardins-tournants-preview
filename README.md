# Jardins tournants - prévisualisation

Copie de travail du site, pour relecture avant mise en ligne.
Le site réel est dans le dépôt jardins-tournants.

Ce dépôt est volontairement écarté des moteurs de recherche par le
fichier robots.txt, qui doit garder sa ligne Disallow: / en permanence.

## Cadre et contenu

Fichiers de cadre, propres à ce dépôt, à ne jamais copier vers la production :
CNAME (absent ici), robots.txt, README.md

Fichiers de contenu, identiques dans les deux dépôts :
index.html, mentions-legales.html, style.css, photos/, polices/

Pour reporter une version validée vers le site réel, copier les fichiers de
contenu et eux seuls.
